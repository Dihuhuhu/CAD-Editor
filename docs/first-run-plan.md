# CAD-Editor 初回実行計画

## 目的
公開済みモデルを使い、入力1件に対するCAD編集が動作するか確認する。

## 担当
- 実行担当：未定
- 結果確認担当：未定

## 実行環境
大学のGPUサーバーを使用する。
接続方法・GPUの割当・保存先は、大学の資料を確認してから確定する。

## 実行手順
1. GPUを確保し、必要な実行環境を準備する。
2. ベースモデルとCAD-Editorの追加モデルを準備する。
3. 配布データから入力を1件だけ取り出す。
4. Locateで編集する箇所を特定する。
5. Infillで編集後のCADデータを生成する。
6. 形状に変換し、元の形状・編集指示と比較する。

## 完了条件
- LocateとInfillが正常終了し、各出力が1件ある。
- 生成結果を形状へ変換できる。
- 指示どおりに変更されたかを確認し、結果を記録できる。

## 記録する情報
コードのバージョン、モデル、入力、実行条件、ログ、生成結果、成功・失敗の内容。
